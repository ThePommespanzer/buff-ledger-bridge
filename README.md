# buff-ledger-bridge

Bridge page for the Buff Ledger Deadlock mod. The game's HUD cannot reach the web, so the mod opens
this page in a hidden HTML panel; the page reads public statistics from
[deadlock-api.com](https://deadlock-api.com) (hero damage per minute by hero and rank, and the rank and stats of the players of a match) and hands them
back to the game through its page title.

Published with GitHub Pages: `https://<github-name>.github.io/buff-ledger-bridge/`.
